# RoomMate

CS 175 group project (Group 2): Aryan, Ananya, Prateek.

An Android app for roommates. Find a match, chat, split bills, rotate chores and share a grocery list.

## Tech

- Java, XML layouts
- Min SDK 24, target SDK 34
- Firebase Auth and Firestore

## Run

1. Open the folder in Android Studio.
2. Let Gradle sync.
3. Run the `app` configuration on an emulator or phone.

## Chores calendar

Select a date and add a weekly chore to create 1–52 dated assignments. Choose the
first assignee; later weeks rotate in the order of the household's `memberIds` at
creation time. Use Reassign to change an individual occurrence. Existing series
are not automatically extended or reassigned if membership changes. Tick an assignment to
mark it complete. Signed-in users need a profile with `householdId`, a household
with members, and Firestore rules permitting household and chore access. Assignees
are currently shown as member IDs. Signed-out users are prompted to sign in.

## Firestore data design

The app uses top-level collections. Every document ID is generated by Firestore,
except `users`, where the document ID is the Firebase Auth user UID.

| Collection | Purpose | Core fields |
| --- | --- | --- |
| `users/{uid}` | Profile and matching preferences | `displayName`, `email`, `householdId`, `budget`, `sleepTime`, `cleanliness`, `smoking`, `pets` |
| `households/{householdId}` | Shared household membership | `name`, `createdBy`, `memberIds[]` |
| `messages/{messageId}` | Household chat messages | `householdId`, `senderId`, `text`, `createdAt` |
| `expenses/{expenseId}` | Shared bills and split metadata | `householdId`, `title`, `paidBy`, `amount`, `splitType`, `createdAt` |
| `chores/{choreId}` | Assigned chores and due dates | `householdId`, `title`, `assignedTo`, `dueAt`, `completed` |
| `groceries/{itemId}` | Shared grocery list | `householdId`, `name`, `addedBy`, `purchased`, `createdAt` |

All shared records carry `householdId`, which is the partition key for queries
and security rules. Timestamp fields are stored as Firestore `Timestamp` values.
The Java representations and canonical collection names live under
`app/src/main/java/edu/sjsu/cs175/roommate/data/`.

## Roommate matching

The Matches screen reads `users/{authUid}` profiles from Firestore, excludes the
signed-in user, and ranks candidates by the percentage of comparable preferences
that match. Budget matches when values differ by at most 20% of the larger value;
sleep time, cleanliness, smoking, and pets match when their values are equal
(text comparisons ignore case). Missing preferences are excluded from the score,
and candidates with no comparable preferences are omitted. Ties favor more
compared fields, then name and document ID.
